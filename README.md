# hxwl-05 海水缸盐度校准与补水放行台

海水缸盐度校准登记与自动补水放行：规则命中即禁止补水，确认即冻结版本，修正留痕。

## 放行规则

- 盐度（比重）必须在 **1.023–1.026** 区间内
- 温度相对 **25.0℃** 偏差不得超过 **0.5℃**
- 校准 **7 天内** 有效，过期禁止补水
- 补水体积按盐度差估算（盐守恒近似）：
  `补水L = 缸体积L × (实测比重 − 1.025) / 实测比重`；
  盐度低于或等于 1.025 时禁止补水
- 估算体积超过补水桶余量时 **整批退回**，不做部分放行
- 同一缸同一自然日仅允许一条校准

## 版本与审计

- 校准确认后立即冻结数值并分配缸内版本号 v1、v2……
- 冻结版本不可改；修正必须填写原因，另起新版本，旧值（字段级）与原因永久保留
- 每张补水单（放行/退回）都回链所依据的校准版本

## 分层结构

| 层 | 位置 | 职责 |
| --- | --- | --- |
| 数据 | `src/data` | 类型定义、演示种子数据 |
| 计算 | `src/domain` | 盐度/温度/过期规则、盐度差补水估算（纯函数） |
| 存储 | `src/storage` | localStorage 仓库（不可变记录、版本递增）与 React store |
| 页面 | `src/components` | 放行台与受阻列、校准登记、版本档案 |

页面标签页：

1. **补水放行台**：每缸盐度、温度、桶余量、校准时间/版本；可放行/受阻状态；受阻列表（鱼缸、盐度、桶余量、命中规则）
2. **校准登记**：读数登记、规则预检，确认后冻结
3. **版本档案**：冻结版本、修正入口、修正审计（原因+旧值）、补水单与版本对应

## 本地运行

```bash
npm install
npm run dev
```
